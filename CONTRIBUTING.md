# Contributing

Thank you for your interest. This is a personal research project, and to keep its licensing simple **pull requests with code, weights or other content are not accepted.**

You are welcome to:
- **Open an issue** to report a bug, a wrong number, or an error in a citation.
- **Fork it** for noncommercial use under the PolyForm Noncommercial License 1.0.0 (see LICENSE).

By opening an issue you agree that any suggestion in it may be used in this project without obligation or attribution. If you need a different arrangement, or want to use Lucid commercially, say so in an issue first and do not post code.

Security problems: see SECURITY.md and report them privately.
