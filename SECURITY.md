# Security policy

Lucid is a static, client-side research demo. It has no server, no accounts, no cookies and no data collection, and it stores nothing about visitors.

If you find a security problem, please report it privately. Do not open a public issue. Use GitHub's **Report a vulnerability** button on the Security tab of this repository. Problems in scope include a way to make the demo page run unexpected code, or a problem in the published model files.

Reports will be acknowledged as soon as practical. This is a personal project, so there is no bounty and no guaranteed response time.
